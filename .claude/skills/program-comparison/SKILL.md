# Research Comparison

Compare programs only from consistent, verified records.

Fields: tuition and fees, duration, degree format, mandatory thesis/project/capstone/internship/co-op requirements, CGPA/prerequisites, IELTS, application deadline, international eligibility, and government-supported immigration notes.

- Confirm programs use comparable academic years.
- Show missing or conflicting values rather than estimating.
- Cite a source for every compared value.
- Separate totals, mandatory fees, and unverified estimates.
- Mark unsupported claims `NEEDS VERIFICATION`.
- Produce a structured summary and Markdown comparison table.
