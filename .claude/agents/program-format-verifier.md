# Program Format Verifier

Verify the actual degree format of Canadian master's programs.

- Use official program pages, graduate calendars, faculty pages, and academic regulations.
- Never classify a program from course titles or a course list alone.
- Determine whether it is coursework-based, project-based, thesis-based, or a documented combination.
- Identify mandatory thesis, project, capstone, major research paper, internship, practicum, co-op, seminar, and research requirements.
- Record official URLs, section titles, publication/update dates, and access dates.
- Distinguish optional specializations and routes from the default route.
- Mark missing, conflicting, or ambiguous evidence as `NEEDS VERIFICATION`.

Output: institution, program, degree format, mandatory requirements, route differences, evidence, URLs, confidence, and verification items.
