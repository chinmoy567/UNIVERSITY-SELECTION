## 4. How I ranked

I ranked in this order:
1. Does a published rule **fail** me? (math grade, 70% minimum, degree type, closed intake) → bottom.
2. Is the overall minimum **3.0 / B average**, and does my **last 2 years** (about 3.47) clear it? → top.
3. Is the program free of math-grade rules? (my math is weak) → higher.
4. Is the rule only **"second class" with no number**, or not stated? → middle. Needs an email.
5. Cost and IELTS break ties.

| Tier | Meaning |
| --- | --- |
| **A** | Best chances on paper. Email first. |
| **B** | Possible. Unclear rule. Email first. |
| **C** | Leaning fail. Apply only if the university confirms in writing. |
| **D** | Fails a published rule. Do not apply. |

| Action | Why |

| Get the capstone (6 credits, A+) added and an **official transcript** | Shows the real CGPA, not 3.29 |
| Ask BAIUST for a letter: grading scale, CGPA, English medium of instruction | Needed for CGPA-to-% conversion. BAIUST's grade table is **not verified** on its public pages. |
| Book IELTS now. Aim for 7.0 | Opens the 7.0 programs |
| Write a strong statement: rising grades (3.04 to 3.61), A+ capstone, AI/ML projects | Helps borderline cases |
| Take a short Linear Algebra / Calculus / Statistics course and show it | Helps with math-grade worries. Check each program first. |
| Add work, internship or certificates (Python, ML, cloud) | Helps in unclear cases |

## 8. My advice

1. **No program is a sure pass.** Apply to 4 or 5, not 2.
2. **Best set to apply:** UCalgary MISP, Dalhousie MDI, Dalhousie MACSc, UWinnipeg. Add Saint Mary's as a fifth.
3. **Email first.** Ask: "Is a Bangladesh CGPA of 3.34/4.00 (about 66%) read as 3.0 or higher?" Send to Dalhousie, UCalgary MISP, UWinnipeg, Saint Mary's and CBU.
4. **UWinnipeg:** also ask "Is the 3.0 one pooled average of computing, math and statistics courses?"
5. **Skip all Tier D programs.** Tier C only with written confirmation.
